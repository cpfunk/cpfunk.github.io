Bringing 2048 to Linux with the ncurses Library

Project Overview

For my final project in EE285 (the sophomore-level C programming class at ISU), I created a version of the hit web game 2048 by Gabriele Cirulli for the Linux shell in C. For this project, I created the terminal user interface (TUI) using the popular Unix library ncurses.

My Role

I developed this project over the Thanksgiving break of fall 2024.

Skills or Knowledge Gained

This project served as my introduction to using the ncurses library in C. It also allowed me to practice developing my code organization skills and many of the C coding concepts taught in EE285. For example, since the game involves shifting and adding the numbers that appear in the 4x4 grid when an arrow key is pressed, this program features multiple nested for loops.

Resources Used

  • In creating this project, I often referenced the original version of the game to observe how the game should behave.
  • To find out how the ncurses library should be used, I frequently consulted linux.die.net and invisible-island.net.

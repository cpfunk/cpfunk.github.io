Bringing 2048 to Linux with the ncurses Library

Project Overview

For my final project in EE285, I created a version of the hit web game 2048 by Gabriele Cirulli for the Linux shell in C. For this project, I created the terminal user interface (TUI) using the popular unix library ncurses.

My Role

I developed this project over Thanksgiving break in Fall 2024.

Skills or Knowledge Gained

This project served as my introduction to using the ncurses library in C. It also allowed me to practise developing my code organization skills, and enabled me to practise many of the C coding concepts taught in EE285; for example, this program features a lot of nested for loops since the game involves shifting the numbers in the 2048 grid when an arrow key is pressed. to the user is a 4x4 grid.

Rresources Used

  • In creating this project, I often used the origional version of the game as a reference for how the game should behave.
  • To find out how the ncurses library should be used, I frequently consulted linux.die.net and invisible-island.net.

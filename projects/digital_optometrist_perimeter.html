Creating a Digital Optometrist Perimeter Control Circuit

Project Overview

For this project, I was paired with another student from EE330 to create a digital perimeter controller using Verilog and Cadence Virtuoso. The project requirements and the controller's behavior were defined in the final project document as follows:


This project will be to design a 64-pixel perimeter. The design is to be completed through post layout simulation. At each pixel location, there will be an LED. The perimeter randomly and sequentially generates a light signal at each of the pixel locations. The time between generating the test signals should be between 7 sec and 20 sec and vary enough so the patient cannot predict when the next signal will be applied. The patient is asked to click on an SPST momentary switch every time a light is observed. A successful detection is to be recorded if the SPST is clicked within 5 seconds of applying the stimulus. At the conclusion of the test, the perimeter should have in memory the number of correct detections. Occasionally, a patient may click if there is no signal present, and this will be defined as a false click. The number of false clicks should also be recorded. After the test is over, the number of successful clicks and the number of false clicks should be displayed on a 4-digit 7-segment display. You may specify any commercial 4-digit 7-segment display. The technician conducting the test will have two switches to control the perimeter. One is a toggle switch which should be used as an input to determine whether the displayed output is the number of successful clicks or the number of false clicks. The other is an SPST push-button switch that will start another test. This readout should remain active after the test is completed until another test is initiated.

 — Final Projects Document EE330
In addition to the digital circuit, there were several smaller analog portions that were required to ensure this circuit's functionality; for example, we created a 16 MHz ring oscillator and a Schmitt trigger to allow for more straightforward debouncing of the push button's input signal.

My Role

I wrote a large portion of the core functionality of this module, including the pseudo-random number generator, the state machine, among others. I also created schematics, layouts, and testbenches for the various analog components like the LED drive transistors, the 16 MHz ring oscillator, and the Schmitt trigger used for providing hysteresis for the button input. When it came to creating the final layout, my partner and I were logged into the same machine, so we worked on the layout in Cadence simultaneously.

Skills or Knowledge Gained

Throughout the course of this project, I was able to practice and learn several critical skills related to integrated IC design:

  • I learned how to synthesize and perform place and route digital circuits using Cadence Genus and Innovus.
  • I learned how to use Cadence Virtuoso to create integrated circuit layouts.
  • I learned how to perform analog mixed-signal simulations using Cadence Spectre AMS Designer.
  • I learned how to design a ring oscillator and a Schmitt trigger.
